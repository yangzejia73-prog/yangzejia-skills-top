# Roadmap

The roadmap is evidence-driven. Dates are targets, not promises.

## v0.2.0 — pilot feedback

- Collect reproducible feedback from at least five creators.
- Add tested output schemas for the six initial Skills.
- Fix failures demonstrated by public Issues.
- Publish an anonymized pilot summary without inflating adoption claims.

## v0.3.0 — maintainer automation

- Add deterministic frontmatter and permission-schema validation.
- Add regression fixtures for prompt injection and unsupported claims.
- Generate a reviewer checklist for Skill-changing Pull Requests.

## Later, only when justified

- Additional platform Skills based on demonstrated demand.
- Optional network-backed research with explicit source and permission controls.
- Packaging or installation tooling after compatibility is tested.

## Non-goals

- Guaranteed virality, engagement, revenue, or platform compliance.
- Automated account access or publishing without action-time consent.
- Collecting private creator data to manufacture usage metrics.
