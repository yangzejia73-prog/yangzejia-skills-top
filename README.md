# Yangzejia Skills Top

A curated open-source collection of practical AI Agent Skills.

The project focuses on reusable skills for AI-assisted workflows, including
content creation, research, automation, document processing, and agent workflows.

## Goals

- Build reusable Agent Skills
- Keep each Skill independently documented
- Provide clear usage examples
- Document permissions and security boundaries
- Accept community feedback and contributions

## Status

This project is under active development.
