# Creator Pilot / 创作者早期试用计划

本计划面向愿意公开报告可复现问题的中文自媒体创作者。参与免费，不要求提供账号密码、后台截图、未发布稿件或个人身份信息。

## 试用方法

1. 选择一个 Skill，并准备经过脱敏的真实任务。
2. 记录使用的 AI 工具、模型（如愿意公开）、Skill 版本和输入摘要。
3. 判断输出是否节省时间、是否遗漏事实、是否保持你的表达意图。
4. 使用仓库的 **Skill request** Issue 模板提交反馈。

## 建议反馈字段

- 使用的 Skill 和版本
- 创作平台与内容类型
- 原本最费时的步骤
- 有帮助的输出
- 错误、幻觉或风险
- 预期行为
- 可公开的最小复现输入

## 隐私

不要提交真实凭证、联系方式、受访者隐私、付费内容、客户材料或未授权作品。需要私下处理的安全问题请遵循 `SECURITY.md`。

## 如何统计

项目只把可验证的 Issue、PR、Release 和公开引用作为维护证据。单次访问、私聊或无法核验的口头反馈不会被描述成“用户量”。
